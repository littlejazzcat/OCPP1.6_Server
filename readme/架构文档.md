# OCPP 1.6 CSMS 程序架构

## 一、项目概述

基于 Python 的 OCPP 1.6 充电站管理系统（CSMS），提供 WebSocket 协议网关、Web 管理界面、远程命令调度、报文实时监控等功能。参考 Monta OCPP Toolkit 的 UI 布局设计。

- **协议库**：`mobilityhouse/ocpp`
- **WebSocket 库**：`websockets`
- **Web 框架**：`FastAPI` + `Jinja2`
- **数据库**：`SQLAlchemy 2.0` async + `aiosqlite`
- **打包**：`PyInstaller` onedir

## 五、OCPP 协议层

### 5.1 连接管理（server.py）

```
充电桩连接 → ws://host:9000/{charge_box_id}
  ↓
on_connect()                          # 注册连接
  ├── cp_set_online(True)             #   立即标记在线
  ├── connections[id] = handler       #   加入连接池
  └── handler.start()                 #   进入 OCPP 消息循环
        ↓
  handler.on_disconnect()             #   断开 → online=False
```

### 5.2 消息路由（charge_point.py）

继承 `ocpp.v16.ChargePoint`，覆写三个关键方法：

| 方法 | 方向 | 说明 |
|------|------|------|
| `route_message()` | IN | 捕获入站 CALLRESULT/CALLERROR，补发到消息总线 |
| `_send()` | OUT | 捕获发出的所有消息，记录 msg_id → action 映射 |
| `@on(Action.xxx)` | IN | OCPP 1.6 上行消息处理器（12 个） |

**上行消息处理器**（桩 → 服务端）：

| 处理器 | 消息 | Handler 配置 |
|--------|------|:---:|
| `on_boot_notification` | BootNotification | status / interval / behavior |
| `on_heartbeat` | Heartbeat | 仅更新心跳时间 |
| `on_authorize` | Authorize | status / behavior |
| `on_start_transaction` | StartTransaction | status / behavior |
| `on_stop_transaction` | StopTransaction | behavior |
| `on_meter_values` | MeterValues | 存储采样 |
| `on_status_notification` | StatusNotification | 更新连接器状态 |
| `on_data_transfer` | DataTransfer | 透传 |
| `on_diagnostics_status_notification` | DiagnosticsStatusNotification | 仅日志 |
| `on_firmware_status_notification` | FirmwareStatusNotification | 仅日志 |

**远程命令（服务端 → 桩）**：19 个 `send_xxx()` 方法

| 命令 | OCPP Action |
|------|------------|
| send_reset | Reset |
| send_remote_start | RemoteStartTransaction |
| send_remote_stop | RemoteStopTransaction |
| send_change_configuration | ChangeConfiguration |
| send_get_configuration | GetConfiguration |
| send_clear_cache | ClearCache |
| send_unlock_connector | UnlockConnector |
| send_trigger_message | TriggerMessage |
| send_update_firmware | UpdateFirmware |
| send_get_diagnostics | GetDiagnostics |
| send_set_charging_profile | SetChargingProfile |
| send_clear_charging_profile | ClearChargingProfile |
| send_get_composite_schedule | GetCompositeSchedule |
| send_get_local_list_version | GetLocalListVersion |
| send_send_local_list | SendLocalList |
| send_cancel_reservation | CancelReservation |
| send_reserve_now | ReserveNow |
| send_raw | 原样透传 |

### 5.3 Handler 运行时配置（handler_config.py）

```
Web UI 修改
  ↓  POST /api/handler-config/{action}
handler_config.set_config(action, config)
  ↓  内存字典同步
charge_point.on_authorize() / on_boot_notification() 等
  ↓  运行时读配置
覆盖 status / behavior (Normal/Delay/Drop) / delay / interval
```

支持 5 个动作：`authorize` / `boot` / `start_tx` / `stop_tx` / `data_transfer`

### 5.4 消息总线（message_bus.py）

```
OCPP 层 publish(msg) → _message_history (内存)
                     → _message_queue (asyncio.Queue)
                            ↓
SSE drain → sse/sse.py → StreamingResponse → 前端 EventSource
```

| 功能   | 实现                                     |
| ---- | -------------------------------------- |
| 全局队列 | asyncio.Queue(maxsize=500)，满时丢弃最旧      |
| 历史缓存 | 无上限 list，重启清空                          |
| 分页查询 | `get_history_page(offset, limit)` 从新到旧 |
| 清空历史 | `clear_history()`                      |

## 十、数据库会话管理

所有数据库操作遵循模式：

```python
async with async_session() as db:
    result = await service.method(db, ...)
    await db.commit()
```

- `expire_on_commit=False`：避免 commit 后属性过期
- 每个请求/消息独立的短事务
- 无连接池复用问题（SQLite 单文件场景）
